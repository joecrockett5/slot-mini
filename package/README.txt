slot-mini for Onion OS (Miyoo Mini Plus)
========================================

Install
    Unzip so that App/slot-mini/ lands on the root of the SD card. Start it
    from Apps -> slot-mini. Nothing else on the card is changed.

Controls
    Left / Right    browse        L1 / R1   switch GBA, GBC, GB, Favorites
    Up / Down       jump a letter Y         heart / unheart
    A (tap)         play, resume the auto save state
    A (hold)        play from the start, without loading the state
    SELECT          cart studio   MENU      about, sounds, boot launcher, exit

Boot launcher (optional)
    MENU -> Boot launcher: On makes slot-mini start in place of Onion's main
    menu. Hold L2 while it starts, or pick Exit to Onion, to get Onion's menu.
    MENU -> Boot launcher: Off puts Onion's menu back.

Uninstall
    Turn Boot launcher off first if you turned it on, then delete
    App/slot-mini/. Labels/ and its files are slot's format and can stay.

Full documentation: https://github.com/joecrockett5/slot-mini
